Évolutions du logiciel

Ce qui a changé à chaque version d'Oz-Alerte, de la plus récente à la plus ancienne.

Version 0.4.7 (build 23)

  • Nouveau profil Voyage / taxi, VTC :
    • Bouton « Je monte dans un taxi / VTC » : photo discrète de la plaque (sans flash ni bruit), plaque lue sur le téléphone sans internet, à vérifier.
    • Un SMS part aux proches avec la plaque, Taxi / VTC, la compagnie, la destination et la position ; le minuteur de sécurité démarre jusqu'à l'arrivée prévue. Sans confirmation, l'alerte part avec la plaque.
    • « Envoyer aussi la photo par MMS » : Messages s'ouvre avec les contacts et la photo, il reste à toucher Envoyer.
  • Photo discrète des lieux (profils Voyage et Personne en danger) : photo sans flash, envoyée par MMS avec l'heure et la position.
  • Photos gardées dans l'espace privé de l'application (20 dernières), jamais dans la galerie.
  • Nouvelle autorisation : appareil photo. Nouveaux composants : camera, google_mlkit_text_recognition.

Version 0.4.6 (build 22)

  • L'application s'appelle désormais Oz-Alerte (icône, écrans, SMS, e-mails, site). L'identifiant Google Play ne change pas.

Version 0.4.5 (build 21)

  • Mode discret et sauvegarde : aucune trace visible quand le mode discret est actif. Pas de copie dans Téléchargements (l'ancienne est supprimée), pas de rappel d'envoi, e-mail « Sauvegarde » et pièce jointe « sauvegarde.dat » au nom neutre.
  • Le fichier de sauvegarde ne contient plus le nom de l'application en clair. Les fichiers de la 0.4.4 restent lisibles.
  • Code de secours de 12 caractères (XXXX-XXXX-XXXX) pour les nouveaux codes, beaucoup plus résistant si le fichier est volé. Les codes de 8 caractères déjà créés restent valables.

Version 0.4.4 (build 20)

  • Sauvegarde de la configuration (Réglages > Sauvegarde) :
    • Chiffrée (AES-256) avec le code de secours, le même que pour le code parent oublié : un seul code à retenir. Il est désormais proposé à tous les profils.
    • Refaite automatiquement à chaque changement : copie sur le téléphone et dans Téléchargements/OzAlerte (Android 10 et plus).
    • Bouton « M'envoyer la sauvegarde par e-mail » (pièce jointe d'environ 3 à 10 Ko) et rappel quand la configuration a changé depuis le dernier envoi.
    • Restauration au premier lancement (« J'ai une sauvegarde ») ou dans Réglages.
    • Contenu : contacts, réglages, codes, zones, trajets, proches suivis. Ni journal, ni enregistrements, ni photo du mode discret.
  • Le code de secours n'est plus remplacé à chaque changement de code parent, ni effacé par la réinitialisation par SMS.
  • Réglages > Aide et informations : liens vers le site, la notice, les évolutions et la politique de confidentialité.

Version 0.4.3 (build 19)

  • Lien « Politique de confidentialité complète » dans À propos > Mentions légales (exigé par Google Play).
  • Éditeur : Oz-Vitrine, contact ozvitrine+ozalerte@gmail.com.
  • Mentions légales mises à jour (chiffrement, sauvegarde désactivée, envoi du journal, test sur Google Play).

Version 0.4.2 (build 18)

  • Code parent oublié : bouton « Code oublié ? » sur la demande de code.
    • Code de secours (8 caractères) affiché une seule fois quand le parent choisit son code ; Réglages > « Code de secours » pour en générer un nouveau.
    • Par SMS : un contact envoie « CODE OUBLIE » (ou « FORGOT CODE »), reçoit un code de confirmation et répond « CONFIRMER X12 » dans les 15 minutes. Fonctionne même protection arrêtée. 3 demandes par jour et 3 essais au maximum.
    • Dans les deux cas, tous les contacts sont prévenus par SMS.
  • Code parent : pause de 5 minutes après 5 codes erronés.
  • Conseils « Empêcher l'extinction » : Google Family Link détaillé, avertissement sur la désinstallation.

Version 0.4.1 (build 17)

  • Sécurité des données : réglages, contacts, codes, journal et enregistrements chiffrés sur le téléphone (AES-256, clé dans le coffre Android). Migration automatique des anciennes données au premier lancement.
  • Sauvegarde Google désactivée : les données ne partent plus dans le cloud ni vers un nouveau téléphone. Après un changement de téléphone, il faut refaire la configuration.
  • Envoyer le journal au développeur (Journal, ou Réglages > Journal) : e-mail prêt à envoyer avec le modèle du téléphone, la version d'Android, les réglages principaux et le journal. Numéros, positions, liens et noms des contacts sont masqués. L'utilisateur relit et choisit le destinataire.
  • Écran « Périmètre validé » mis à jour avec toutes les fonctions 0.2.5 à 0.4.1 (statut « à tester »).

Version 0.4.0 (build 16)

  • Application multilingue : français (langue d'origine) et anglais, choix au premier lancement et dans Réglages > Langue et pays.
  • Langue des SMS réglable par contact.
  • Numéros d'urgence par pays (12 pays + « autre pays »), détection automatique du pays où l'on se trouve à l'étranger.
  • Numéro « mon téléphone » mis au format international selon le pays.

Version 0.3.2 (build 15)

  • Réponses par SMS des proches avec code (SIRENE, STOP SIRENE, POSITION, FIN…), 3 essais maximum.
  • Relance automatique des contacts qui ne répondent pas.
  • Minuteur de sécurité « Je suis bien arrivé ».
  • Détection d'immobilité.
  • Mode exercice : alerte de test signalée comme telle aux proches.
  • Corrections : code de contrainte toujours silencieux, drapeau de contrainte conservé lors des relances, « STOP SIRENE » n'arrête plus l'alerte.

Version 0.3.1 (builds 13–14)

  • File d'attente des SMS : renvoi automatique quand le réseau revient.
  • Règles anti-détournement : zones, trajets et code parent réservés au profil Enfant ; mode discret réservé aux profils Danger et Personnalisé.
  • Consignes pour les contacts sur iPhone (SMS de test lisible, mode d'emploi).

Version 0.3.0

  • Mode discret : faux écran de verrouillage avec photo en fond et code d'alerte. Ne bloque jamais le verrouillage automatique du téléphone tant que l'alerte n'est pas donnée.

Version 0.2.9

  • SMS automatique quand le téléphone s'éteint ou passe en mode avion (tous profils).
  • Encadré de conseils pour empêcher l'extinction ou le mode avion chez un enfant.
  • Code parent pour protéger l'accès aux réglages.

Version 0.2.8

  • Marge de distance réglable pour la surveillance de trajet.

Version 0.2.7

  • Enfant : surveillance de trajet A → B (alerte si l'enfant s'éloigne de B ou n'arrive pas à temps, avec position immédiate).

Version 0.2.6

  • Enfant : zones GPS (gare, aéroport, gare routière…) avec alerte complète à 100 m, définies à partir d'un lien Google Maps.

Version 0.2.5

  • Délais réglables depuis l'icône de réglage.

Version 0.2.3 – 0.2.4

  • Préparation de la publication Google Play (signature, identifiant fr.oz_vitrine.oz_bouton_dalerte).

Versions 0.1 à 0.2.2

  • Page d'alerte plein écran (appui 1,5 s) et bouton SOS dans la notification.
  • SMS d'alerte avec position, batterie et autonomie ; appel automatique du contact principal ; positions régulières.
  • Détection de choc / chute avec « Tout va bien ? ».
  • Enregistrement audio, sirène, flash, écran basse consommation.
  • Code d'arrêt et code de contrainte ; dernier SMS à 5 % de batterie.
  • Côté proches : sonnerie de réveil, fiche de suivi, accusé « vu », commandes à distance pendant une alerte.
  • Choix du profil au premier lancement.
